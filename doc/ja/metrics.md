# 指標の定義について

集計の単位は **seat**（1 試合に参加した 1 エージェント）です。チームの値は、そのチームの seat の分子と分母をそれぞれ足してから割ります。したがって大会中に逐次で出した値と、大会後にまとめて計算した値は必ず一致します。

決着まで進んだ試合（`success` ログ）だけを数えます。

## 5 系統

### 勝率

| 列 | 定義 |
|---|---|
| `勝率_macro` | 勝った試合数 ÷ 参加試合数。実際にどれだけ勝ったか |
| `勝率_micro` | 役職別勝率の単純平均（1 度以上引いた役職のみ）。どの役職でも満遍なく勝てるか |
| `勝率_weighted_micro` | 役職別勝率を、その村の役職構成で重み付けして平均したもの。配役の偏りを打ち消した勝率 |

役職構成はデータセットの全 seat を役職別に数えて求めます（5 人村なら 村人 2 : 占い師 1 : 狂人 1 : 人狼 1）。配役が構成比どおりなら macro と weighted micro は一致し、3 つが割れたときは配役が偏っていた合図です。役職別勝率は「勝率 (勝ち数 / 試合数)」の形で併記します。

### 〜やすさ（ランダム比）

**実測回数 ÷ ランダムだったときの期待回数** です。1.0 がランダム相当、2.0 ならランダムの 2 倍。

率（回数 ÷ 機会数）ではなくランダム比にするのは、候補者の人数で基準が動くためです。5 人村の投票は自分以外の 4 人が候補なので、完全にランダムでも被投票率は 0.25 になります。9 人村なら 0.125 です。ランダム比なら 5 人村と 9 人村、序盤と終盤を並べて比べられます。

期待回数は「実際に起きた出来事を、その時点の候補者に均等に配った量」です。たとえば 5 人生存の日に他の 4 人が投票すれば、各人に 4 × 1/4 = 1 票が期待されます。実際に 3 票受けていれば狙われやすさは 3.0 です。

| 列 | 回数 | 候補 |
|---|---|---|
| `追放されやすさ` | 追放された回数 | その日の生存者（1 日 1 追放を均等配分） |
| `狙われやすさ` | 受けた票（自己投票を除く） | 投票者以外の生存者 |
| `占われやすさ` | 占われた回数 | 占い師以外のその夜の生存者 |
| `守られやすさ` | 護衛された回数 | 騎士以外のその夜の生存者。騎士のいる村のみ |
| `注目されやすさ` | 自分のキャラ名を含む他者の発言数 | 発言者以外の生存者（1 発言が言及した人数を均等配分） |
| `襲われやすさ` | 人狼に襲撃された回数 | その夜の生存者から人狼を除いた者 |
| `襲撃候補にされやすさ` | 人狼の襲撃投票で指名された回数 | 同上。人狼が 1 体の村では襲われやすさと一致 |

「被◯◯」系のランダム比は、票や占いが必ず誰か 1 人に入る以上、データセット全体で加重平均すると構造上ぴったり 1.0 になります（基準線の検算に使えます）。

### 精度（ランダム比）

| 列 | 定義 |
|---|---|
| `占い精度` | 占い師のとき人狼を占った回数 ÷ ランダムに占ったときの期待回数 |
| `投票精度_村人陣営` | 村人陣営のとき人狼に投じた票 ÷ ランダムに投じたときの期待票数 |

期待は「候補者に占める人狼の割合」です。こちらは全体で 1.0 に収束せず、1.0 からのずれがエージェントの実力を表します。

### 連携

| 列 | 定義 |
|---|---|
| `人狼以外への投票率_狂人` | 狂人のとき人狼以外に投じた票の割合。狂人は仲間の人狼を知らされないので、避けるには自力の推定が要る |
| `人狼への投票率_人狼` | 人狼のとき自分以外の人狼に投じた票の割合（仲間撃ち率）。人狼が 2 体以上の村のみ。誤りの場合も、疑いを逸らす戦略の場合もある |

### エラー挙動

意図していないはずの挙動を「回数 (機会)」で数えます。順位は付けません。

| 項目 | 回数 | 機会 |
|---|---|---|
| 投票せず | 生存しているのに投票の記録が無い日 | 生存して迎えた投票日 |
| 自分に投票 | 投票の対象が自分 | 投じた票 |
| 襲撃投票せず | 人狼なのに襲撃投票の記録が無い夜 | 人狼として迎えた夜（1 日目以降） |
| 仲間を襲撃指名 | 襲撃投票の対象が人狼（自分を含む） | 襲撃投票 |
| 占わず | 占い師なのに占いの記録が無い夜 | 占い師として迎えた夜（0 日目から） |
| 護衛せず | 騎士なのに護衛の記録が無い夜 | 騎士として迎えた夜（1 日目以降） |
| 無発言の日 | 発言が Over / Skip だけだった日 | 発言できた日 |
| 同一発言の連投 | 直前と同じ本文を続けて発言した回数 | 発言数 |

夜の有無は、0 日目は必ずあるものとし、1 日目以降はサーバが必ず書く `attack` 行で判定します。死者への投票・占い・護衛と、占い・護衛の自己対象はサーバが拒否するためログに現れません。

## 出力ファイル

`data/output/<トラック>/`

| ファイル | 内容 |
|---|---|
| `seats.csv` | seat 単位の生データ。全指標の分子・分母 |
| `team_summary.csv` | チーム別の 5 系統（`dataset`, `team` で 1 行） |
| `team_by_role.csv` / `team_by_camp.csv` | チーム × 役職 / 陣営の分子・分母と率 |
| `execute_by_day.csv` | DAY 別の被追放率（その日を生存して迎えた回数を分母にした条件付き率） |
| `issues.txt` | 読み込み時の警告 |

`seats.csv` に分子・分母が全部入っているので、別の切り口が欲しいときは `aiwolf_nlp_calculate_score.metrics.aggregate(seats, ["dataset", "team", "role"])` のように再集計できます。
